# Observar una clase: paper de uso y guía de la idea

**Observatorio de clase.** Para que una escuela chica observe clases y les dé a sus docentes una devolución: quién habla, qué se pregunta, cuánto se espera y quiénes participan. Una herramienta para mejorar, nunca un puntaje ni una sanción.

Paper de uso y guía de la idea detrás de **[Classroom Observatory](https://github.com/LoiaconoBruno/classroom-observatory)**. Explica cómo se usa la herramienta, cómo funciona por dentro y qué dicen los especialistas sobre la idea de fondo, con referencias verificables.

- 📄 **[Leer el paper](https://loiaconobruno.github.io/classroom-observatory-paper/)**
- 💻 **[Código](https://github.com/LoiaconoBruno/classroom-observatory)**
- ▶ **[Probar la herramienta](https://loiaconobruno.github.io/classroom-observatory/)**

> Preprint de Bruno Loiacono, estudiante de Física (Universidad de Buenos Aires). Documento de trabajo sin revisión por pares. Forma parte de [Ideas](https://github.com/LoiaconoBruno/ideas).

## Cómo se genera

`paper.md` es la fuente. La versión web (`index.html`) se arma con un script sin dependencias:

```bash
python3 tools/guia.py
```
